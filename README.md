Universal command-line tool that applies AI-written edits in four formats (`unified`, `search-replace`, `v4a`, and `json`) to a tree of text files according to `SPEC.md`.

## Features
- Full support for Unified Diffs with wrong line numbers, file creations, moves, deletions, and no-newline handling.
- Full support for SEARCH/REPLACE blocks.
- Full support for V4A patch format with anchors, EOF chunks, and file moves.
- Full support for JSON edit arrays and JSON Lines format.
- 3-tier fuzzy line matching (exact, trailing whitespace removed, leading/trailing whitespace normalized).
- All-or-nothing atomic writes and `--check` dry-run mode.
